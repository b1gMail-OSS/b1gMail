# Installation
Zur Installation des PremiumAccount-Plugins folgen Sie bitte der Anleitung in diesem Artikel.

## System-Anforderungen
Um das PremiumAccount-Plugin nutzen zu können, müssen mindestens die folgenden Anforderungen erfüllt sein:

* Einsatzbereite Installation von b1gMail ab Version 7.2.0 (ältere PremiumAccount-Plugin-Versionen sind auch mit älteren b1gMail-Versionen kompatibel)
* Mindestens 5 MB freien Webspace
* Für anfallende Benutzer- und Zahlungsdaten sollte mindestens 2-5 MB freier Speicher in der MySQL-Datenbank von b1gMail vorhanden sein


## Installation des Plugins
Dank des Plugin-Systems von b1gMail gestaltet sich die Installation sehr einfach.

1. Aktivieren Sie das PremiumAccount-Modul unter Plugins.
1. Konfigurieren Sie nun b1gMail, um Zahlungen empfangen zu können. Rufen Sie dazu die Seite 'Einstellungen' -> 'Zahlungen' im Administrationsbereich auf.

## Abschluss
Die Installation des Plugins ist nun abgeschlossen. Sie sollten das Plugin nun entsprechend Ihrer Bedürfnisse konfigurieren. Lesen Sie dazu bitte im Kapitel [Administration](Administration.md) weiter.
